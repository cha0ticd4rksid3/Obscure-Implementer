**Obscure Implementer**

Это зверь для внедрения вредоносного кода 
в скрипты python.

**R4Id и R4id+**

R4Id - Собирает файлы пользователя и отправляет в телеграм.
R4Id+ - При запуске на Windows захватывает экран и
делает шот с веб камеры. Крадет пароли с браузеров:
Chrome и Firefox.
R4Id+ При запуске на Termux предоставляет доступ к консоли. 
Все еще в разработке.

**HiFiles**

HiFiles - Предоставит тебе простой и мгновенный
доступ к файловой системе пользователя.

**InterGram**

InterGram - Пользователь удаленного устройства вводит данные своего телеграм аккаунта.
Данные отправляются тебе.

**ExSystemKiller**

ExSystemKiller - Является вирусом вымогателем, стирает все файлы на удаленном устройстве.

**PCcontrol**

PCcontrol - Простой тул удаленного доступа к ПК.
Предоставляет широкий функционал.
